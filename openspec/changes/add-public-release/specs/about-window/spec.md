## Purpose

Tells users which version of Blockout they run, under which free license, and where to find its source.

## ADDED Requirements

### Requirement: About content
The About window SHALL show the app name and icon, the installed version, the statement that Blockout is free software under the GNU GPL-3.0 without warranty, links to the source repository and to the license text, and the update section.

#### Scenario: Opening About
- **WHEN** the user opens About from the app menu or Settings
- **THEN** the window shows the version, the GPL-3.0 notice with both links and the update status
